=== [Unreleased]

=== Changed
* Standard knot table 5_2..7_7 now pinned from signed KnotAtlas PD codes.
  The Dowker--Thistlethwaite reconstruction (shared with KnotTheory.jl's
  own table data) provably rebuilds the wrong knots beyond 5_1, so every
  table knot is fixed by an exhaustive sign search against the knot's
  published KnotAtlas Alexander and Jones polynomials, cross-checked
  through the Atlas braid-word closure. `from_dt` is retained as a utility
  with the limitation documented; the table itself no longer uses it.
* Alexander Fox row now takes its Laurent exponent from the crossing
  geometry (which slot the over-strand enters) instead of the crossing
  sign. The sign-based formula silently corrupts diagrams whose crossings
  mix over-strand directions (e.g. the KnotAtlas 6_3 diagram); the
  geometric rule reproduces the published Alexander polynomial of every
  knot 3_1..7_7.

=== Added
* Test pins: KnotAtlas Alexander and Jones polynomials plus determinants
  and genera for every nontrivial table knot.

== [0.1.0] - 2026-09-25

=== Added
* KnotKnot.jl: knot theory across the theory--practice divide.
* Theory layer: KnotAtlas-convention PD kernel, Jones (Kauffman bracket),
  Alexander--Conway (Fox calculus + Bareiss), band-based signature, genus,
  finite quandles and colouring counts, braid closure, rational tangles,
  two-bridge classification, and skein triples with the Conway relation
  verified per crossing.
* Practice layer: elastic-rod knot mechanics (capstan friction,
  bend-stress superposition, breaking force, rope efficiency),
  writhe/linking integrals, Calugareanu--White--Fuller check.
* Protistology layer: flagellar waveform analysis and kinetoplast
  catenane chains with linking matrices (future Proctist.jl seed).
* One-call `conway_suite` report with human-readable and JSON rendering.
* Web laboratory (www/public/knot-lab/) overlaying Julia-evaluated theory
  annotations on the tensile mechanics simulation.
* interop/ cross-validation environment against KnotTheory.jl and Skein.jl
  (URL-resolved, on demand).
* Justfile golden path wired for Julia: build / test / fmt-check / lint /
  quality / report / catalog / serve / interop.
* Documenter build (docs/make.jl) gated by julia-docs.yml; deploy deferred
  per docs/decisions/0004-docs-build-only.adoc.
* Axiom.jl hand-off: training-data and proof-obligation export
  (examples/axiom_bridge.jl).

=== Changed
* Estate descriptiles (CLADE, STATE, ECOSYSTEM) rewritten for knot-knot.
* README, CONTRIBUTING, decisions and planning docs instantiated.
