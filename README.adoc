*KnotKnot.jl* carries knot theory across the *theory–practice divide*. On
the theory side: planar- and Gauss-code diagram kernels, Jones and
Alexander–Conway invariants, quandles and colouring counts, braid closures,
and Conway's rational-tangle calculus. On the practice side: elastic-rod
knot mechanics (capstan friction, bend-stress superposition, rope-efficiency
prediction) and protistological topology (flagellar waveform analysis,
writhe/linking integrals, kinetoplast catenation). One
`conway_suite` call evaluates the full Conway suite of any diagram.

Instantiated 2026-09-25 from `hyperpolymath/rsr-template-repo` with the
`julia-library` archetype; provenance in
link:.machine_readable/PROVENANCE.a2ml[.machine_readable/PROVENANCE.a2ml].
The planning document is link:docs/governance/planning/ULTRAPLAN.adoc[the ULTRAPLAN].

== Quick start

[source,bash]
----
julia --project=. -e 'using Pkg; Pkg.instantiate()'   # or: just build
julia --project=. -e 'using KnotKnot; println(conway_suite("3_1"))'

just test        # Aqua package-shape gate + behavioural cases
just quality     # fmt-check + lint (JET) + test
just catalog     # regenerate the web-laboratory JSON
just serve       # open the laboratory on http://localhost:8081
----

The package is *stdlib-only* by design (`LinearAlgebra`, `Printf`): the
applied layers never depend on the registry availability of the theory
engines.

== What's inside

[cols="1,2"]
|===
| Theory
| PD/Gauss diagram kernel (KnotAtlas convention), Jones via Kauffman bracket,
Alexander–Conway via Fox calculus, signature/genus from Seifert data,
finite quandles and fundamental-quandle colourings, braid closure,
rational tangles and 2-bridge classification, skein triples with the
Conway relation verified per crossing.

| Practice
| `Rod` mechanics: curvature profiles, Euler–Bernoulli bending energy,
capstan tension propagation, stress superposition
`σ = F/A + E·κ·d/2`, safety factors, breaking-force and knot-efficiency
prediction; Gauss-integral writhe/linking and the
Calugareanu–White–Fuller identity.

| Protistology
| Flagellar waveform generators (planar / helical / tipped) with beat-cycle
bending-load analysis; kinetoplast-DNA catenane chains with pairwise
linking matrices — the seed of a future `Proctist.jl`.

| Bridges
| Conway-suite report, JSON export (`export_knot_record`,
`write_visualization`), KnotTheory.jl PD-dict round-trips, Skein.jl-format
Gauss codes, Axiom.jl training-data hand-off (`examples/axiom_bridge.jl`),
and a web laboratory (`www/public/knot-lab/`) that layers the Julia-evaluated
theory annotations over the tensile mechanics view.
|===

== The estate cluster

KnotKnot is the bridge package of the hyperpolymath knot-theory cluster:

* `hyperpolymath/KnotTheory.jl` — the classical diagram/invariant engine.
  KnotKnot pins its PD conventions against it and cross-validates in
  `interop/` (`just interop`, URL-resolved).
* `hyperpolymath/Skein.jl` — skein relations, bracket polynomials,
  knot-record storage. KnotKnot emits compatible Gauss codes and records.
* `hyperpolymath/Axiom.jl` — downstream learner/prover: consumes
  curvature→stress training data and proof obligations exported by
  `examples/axiom_bridge.jl`.
* `hyperpolymath/fraying-model-computational-testbed` — sibling applied
  topology work built on Skein.jl Gauss codes.

== Web laboratory

`www/public/knot-lab/` renders the tensile simulation — capstan friction
core, bend-stress heat-mapping, fracture at UTS — annotated with the Julia
evaluation of the loaded knot: Jones/Alexander/Conway polynomials,
determinant, signature, genus, quandle colouring counts, and skein/quandle
callouts. `just catalog` regenerates its data file from the standard table.

== Repository map

* `src/` — the Julia package (flat module layout, one concern per file).
* `test/` — Aqua shape gate plus pinned-value behavioural cases.
* `interop/` — URL-resolved cross-validation against KnotTheory.jl / Skein.jl.
* `examples/` — report CLI, catalog exporter, stdlib static server,
  Axiom.jl bridge.
* `docs/` — estate governance docs (AsciiDoc) plus the Documenter build
  (`docs/make.jl`, `docs/src/`).
* `www/public/knot-lab/` — the web laboratory.
* `.machine_readable/` — descriptiles, contractiles, policies (RSR).
